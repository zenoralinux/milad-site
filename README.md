# وب‌سایت شخصی میلاد

وب‌سایت شخصی فارسی میلاد با طراحی واکنش‌گرا و هویت بصری بنفش/آبی نئونی.

## امکانات
- رابط کاملاً فارسی و راست‌چین
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- تم تاریک و روشن با ذخیره انتخاب کاربر
- معرفی برجسته ZenoraChat با موکاپ مفهومی گوشی
- معرفی پروژه‌های Zenora Linux و ZenoraChat
- بخش درباره من، اکنون و شبکه‌های اجتماعی
- انیمیشن‌های سبک با پشتیبانی از prefers-reduced-motion
- بدون نیاز به فریم‌ورک یا فرایند build

## اجرا
فایل `index.html` را مستقیماً در مرورگر باز کنید یا مخزن را روی GitHub Pages منتشر کنید.

## شخصی‌سازی
- متن‌ها و لینک‌ها در `index.html` قرار دارند.
- رنگ‌ها در متغیرهای ابتدای بخش CSS تعریف شده‌اند.
- آواتار و پیش‌نمایش گوشی فعلاً گرافیکی و مفهومی هستند و باید در صورت نیاز با تصاویر واقعی جایگزین شوند.

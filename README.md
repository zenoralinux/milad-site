# وب‌سایت شخصی میلاد

وب‌سایت فارسی با CMS اختصاصی PHP/MySQL و صفحه‌ساز بصری Milad Studio.

## امکانات

- صفحه اصلی پویا با حفظ طراحی فعلی
- **صفحه‌ساز بصری زنده:** پیش‌نمایش واقعی سایت داخل پنل و انتخاب هر سکشن با کلیک
- ویرایش زنده فیلدها و تنظیمات ظاهری با ذخیره خودکار؛ بدون Reload پیش‌نمایش
- مرتب‌سازی سکشن‌ها با Drag & Drop و فهرست لایه‌ها
- افزودن، تکثیر، حذف، مخفی‌کردن و ویرایش بلوک‌ها
- موتور چیدمان تو‌در‌تو با Container، Grid و فرزندان قابل مدیریت
- کتابخانه ویجت‌ها: Heading، Paragraph، Button، Image، Card، Divider، Icon، Counter، List، Video و CTA
- مدیریت فرزندان کانتینر و گرید با افزودن، جابه‌جایی و حذف از پنل
- استایل پیشرفته هر بلوک: رنگ، تایپوگرافی، عرض، ارتفاع، فاصله، Border، Shadow و Display
- تنظیمات واکنش‌گرا مستقل برای Tablet و Mobile همراه با پیش‌نمایش زنده
- Undo/Redo برای ویرایش بلوک و Revision Manager برای مشاهده و بازیابی نسخه‌های قبلی
- کتابخانه رسانه با بارگذاری امن تصویر و ویدیو و انتخاب مستقیم فایل برای ویجت تصویر
- قالب‌های شروع آماده برای Feature Grid، CTA و معرفی شخصی
- نوار ابزار زمینه‌ای برای جابه‌جایی، تکثیر، مخفی‌سازی و حذف عنصر انتخاب‌شده
- تنظیم ظاهر کلی: رنگ اصلی، پس‌زمینه، عرض محتوا، گردی گوشه‌ها، مقیاس فونت و فاصله سکشن‌ها
- تغییر عرض پیش‌نمایش واقعی بین دسکتاپ، تبلت و موبایل
- مدیریت محتوای سکشن‌های فعلی و پروژه‌ها
- تنظیمات SEO و لینک‌های شبکه‌های اجتماعی
- تاریخچه نسخه قبل از ذخیره هر بلوک
- مهاجرت نسخه‌ای دیتابیس بدون حذف داده‌های CMS قبلی
- پنل واکنش‌گرا، ورود امن، CSRF و محدودیت تلاش ورود
- سازگار با PHP 7.4.33 و نسخه‌های جدیدتر و MySQL 5.7+ / MariaDB 10.3+

## نصب روی هاست اشتراکی

1. از دیتابیس فعلی نسخه پشتیبان بگیر.
2. برای نصب جدید، دیتابیس MySQL و کاربر آن را از کنترل‌پنل هاست بساز.
3. فایل‌های پروژه را در مسیر سایت آپلود کن.
4. config.example.php را به config.local.php کپی کن و اطلاعات واقعی هاست و مدیر را در آن قرار بده.
5. مسیر /admin را باز کن.

**اطلاعات واقعی هاست فقط باید در config.local.php قرار بگیرند. این فایل در .gitignore است و نباید در GitHub آپلود شود.** در صورت وجود config.local.php، تنظیمات آن روی مقادیر نمونه config.php اعمال می‌شود.

در اولین درخواست پس از استقرار، Installer اولیه و سپس Migrationهای نسخه‌ای اجرا می‌شوند. Migration صفحه‌ساز، محتوای سکشن‌های فعلی را به صفحه اصلی و بلوک‌ها منتقل می‌کند و رکوردهای قبلی را حذف نمی‌کند. فایل SQL را دستی Import نکن.

## ارتقای نصب موجود

- پیش از آپلود نسخه جدید از دیتابیس و فایل‌های فعلی نسخه پشتیبان بگیر.
- فایل config.php خصوصی فعلی را روی هاست حفظ کن یا مقادیر آن را به config.local.php منتقل کن؛ فایل نمونه داخل GitHub نباید جایگزین تنظیمات واقعی هاست شود.
- فایل‌های شاخه جدید را آپلود کن. Migrationها هنگام اولین درخواست اجرا می‌شوند.
- بعد از بالا آمدن صفحه، وارد /admin شو؛ ابزار مستقل «محتوای سایت» حذف شده و تمام سکشن‌های صفحه اصلی، اصول کاری و پاورقی از «صفحه‌ساز بصری» مدیریت می‌شوند.
- اطلاعات قبلی در جدول‌های site_sections و projects حفظ می‌شوند؛ Migrationهای نسخه‌ای، سکشن‌ها، کارت‌های اصول کاری و پاورقی را به مدل صفحه‌ساز متصل می‌کنند.
- پیش‌نمایش زنده با نشست مدیر محافظت شده و داده‌های ویرایش را از طریق پیام‌رسانی same-origin دریافت می‌کند؛ هر تغییر در پیش‌نمایش ویرایشگر فوراً اعمال و سپس خودکار ذخیره می‌شود.

## پیش‌نیازها

- PHP 7.4.33 یا جدیدتر
- افزونه pdo_mysql و ترجیحاً mbstring
- MySQL 5.7+ یا MariaDB 10.3+
- Apache با mod_rewrite و پشتیبانی از .htaccess
- دسترسی CREATE, SELECT, INSERT, UPDATE, DELETE روی دیتابیس

## امنیت

- رمز دیتابیس و مدیر را در مخزن عمومی قرار نده.
- اگر نسخه‌ای از config.php دارای اطلاعات واقعی قبلاً در مخزن عمومی قرار گرفته، تمام رمزهای آن را افشاشده فرض کن و تعویض کن؛ تغییر فایل در آخرین Commit به‌تنهایی تاریخچه Git را پاک نمی‌کند.
- فایل‌های تنظیمات واقعی را از تمام شاخه‌ها و تاریخچه عمومی Git پاک‌سازی کن؛ برای بازنویسی تاریخچه از git filter-repo استفاده کن و سپس Force Push هماهنگ‌شده انجام بده.
- قبل از پاک‌سازی تاریخچه، نسخه پشتیبان خصوصی از مخزن و فایل کانفیگ فعال تهیه کن.
- از HTTPS استفاده کن و app.debug را در محیط واقعی خاموش نگه دار.

## ساختار مهم

    app/bootstrap.php       تنظیمات، اتصال دیتابیس و اجرای Migration
    app/installer.php       نصب اولیه
    app/migrations.php      Migrationهای نسخه‌ای
    app/page_builder.php    دریافت بلوک‌ها و رندر صفحه
    admin/index.php         پنل مدیریت و Milad Studio
    api/admin.php           API احراز هویت‌شده پنل
    assets/css/builder.css  ظاهر صفحه‌ساز
    assets/js/builder.js    تعاملات Drag & Drop، ویجت‌ها و کنترل‌های پیشرفته
    api/media.php           API احراز هویت‌شده کتابخانه رسانه
    config.php              تنظیمات نمونه، بدون رمز واقعی
    config.example.php      الگوی تنظیمات محلی
    config.local.php        تنظیمات خصوصی هاست (در Git نادیده گرفته می‌شود)
    database/schema.sql     ساختار اولیه CMS
    index.php               رندر صفحه اصلی

## مسیرها

- / صفحه اصلی
- /admin پنل مدیریت
- /api/admin.php?action=... API خصوصی پنل

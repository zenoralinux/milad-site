# وب‌سایت شخصی میلاد

وب‌سایت فارسی با CMS اختصاصی PHP و پنل مدیریت.

## قابلیت‌ها

- صفحه اصلی پویا با حفظ طراحی فعلی
- مدیریت متن‌ها و بخش‌های صفحه اصلی
- مدیریت پروژه‌ها، دسته‌بندی‌ها، انتشار و ترتیب نمایش
- تنظیمات SEO و لینک‌های شبکه‌های اجتماعی
- پنل واکنش‌گرا، ورود امن، CSRF و محدودیت تلاش ورود
- سازگار با PHP 7.4.33 و نسخه‌های جدیدتر

## راه‌اندازی روی هاست اشتراکی (بدون ترمینال)

**همه تنظیمات در یک فایل است: config.php. به SSH، ترمینال یا اجرای دستور PHP نیاز نداری.**

1. از کنترل‌پنل هاست (مثلاً cPanel) یک دیتابیس MySQL و یک کاربر دیتابیس بساز و کاربر را به دیتابیس متصل کن.
2. تمام فایل‌های پروژه را در پوشه سایت، مثلاً public_html/site/ آپلود کن.
3. در File Manager همان پوشه، فایل config.php را باز کن.
4. فقط این مقادیر را وارد کن:
   - database.name: نام کامل دیتابیس، با پیشوند هاست
   - database.username: نام کامل کاربر دیتابیس، با پیشوند هاست
   - database.password: رمز کاربر دیتابیس
   - admin.username: نام کاربری ورود به پنل
   - admin.password: رمز ورود مدیر، حداقل ۱۲ کاراکتر
5. فایل را ذخیره کن و /admin را باز کن.

در اولین بازدید، خود سایت جدول‌های دیتابیس را می‌سازد، محتوای اولیه و پنج پروژه را وارد می‌کند و حساب مدیر را ایجاد می‌کند. این کار فقط یک بار انجام می‌شود و اطلاعات موجود را بازنویسی نمی‌کند.

**هیچ فایل SQL را دستی Import نکن و هیچ دستور ترمینالی اجرا نکن.**

### پیش‌نیازهای هاست

- PHP 7.4.33 یا جدیدتر
- افزونه pdo_mysql و ترجیحاً mbstring
- MySQL 5.7+ یا MariaDB 10.3+
- Apache با پشتیبانی از .htaccess
- دسترسی ساخت جدول (CREATE) و درج/ویرایش داده‌ها برای کاربر دیتابیس

### اگر نصب انجام نشد

- دیتابیس و کاربر را در کنترل‌پنل هاست ساخته باش.
- نام دیتابیس و کاربر را دقیقاً همراه پیشوند هاست وارد کن.
- کاربر دیتابیس باید به همان دیتابیس متصل شده و اجازه ساخت جدول داشته باشد.
- مقدار database.host معمولاً localhost است؛ از مقدار اعلام‌شده توسط هاست استفاده کن.

برای نمایش خطای دقیق، فقط موقتاً app.debug را در config.php روی true بگذار و پس از رفع مشکل دوباره false کن.

### امنیت

- مقادیر واقعی دیتابیس و مدیر را در GitHub عمومی Commit نکن؛ فایل روی هاست را با File Manager ویرایش کن.
- دسترسی مستقیم وب به config.php توسط .htaccess مسدود شده است.
- پس از اولین نصب موفق، می‌توانی مقدار admin.password را در فایل کانفیگ خالی کنی؛ رمز هش‌شده در دیتابیس ذخیره شده و ورود با همان رمز ادامه پیدا می‌کند.
- از HTTPS استفاده کن و از دیتابیس نسخه پشتیبان بگیر.

## ساختار

    app/bootstrap.php       اتصال دیتابیس و راه‌اندازی خودکار
    app/installer.php       نصب خودکار بار اول
    admin/index.php         پنل مدیریت
    api/admin.php           API خصوصی پنل
    assets/css/admin.css    طراحی پنل
    assets/js/admin.js      تعاملات پنل
    config.php              تنها فایل تنظیمات
    database/schema.sql     ساختار جدول‌ها
    index.html              نسخه استاتیک جایگزین
    index.php               رندر پویا از دیتابیس

## مسیرها

- /: صفحه اصلی
- /admin: پنل مدیریت
- /api/admin.php?action=...: API پنل

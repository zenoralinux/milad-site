# وب‌سایت شخصی میلاد

بازسازی کامل وب‌سایت شخصی فارسی میلاد با رویکرد **مینیمال لوکس و آینده‌نگر**.

## طراحی و تجربه کاربری

- رابط فارسی و راست‌چین با اولویت موبایل
- هویت بصری تیره با جزئیات بنفش و آبی، همراه با پوسته روشن
- صفحه معرفی با تصویر پروفایل و مسیرهای دسترسی سریع
- ویترین پروژه‌ها با فیلتر دسته‌بندی
- بخش معرفی، تمرکز فعلی و راه‌های ارتباطی
- جست‌وجوی سریع با \`Ctrl + K\` یا \`/\`
- نوار پیشرفت مطالعه و انیمیشن‌های سبک
- رعایت \`prefers-reduced-motion\` و فوکوس قابل مشاهده برای کیبورد
- متادیتای SEO، Open Graph، داده ساختاریافته و sitemap

## اجرا و انتشار

این پروژه استاتیک است و به Node.js، فریم‌ورک، بسته خارجی یا مرحله build نیاز ندارد. فایل‌ها را روی هاست فعلی یا GitHub Pages منتشر کنید.

## شخصی‌سازی

- متن‌ها، لینک‌ها و پروژه‌ها در \`index.html\` هستند.
- رنگ‌ها، فاصله‌ها و اجزای واکنش‌گرا در \`assets/css/site.css\` تعریف شده‌اند.
- تعاملات رابط کاربری در \`assets/js/site.js\` قرار دارند.
- تصویر پروفایل از فایل \`milad_avatar.jpg\` موجود در ریشه استفاده می‌کند.
- آدرس canonical و sitemap روی \`https://miladalizadw.ir/\` تنظیم شده‌اند.

# راهنمای نصب گرافیکی Milad CMS (بدون ترمینال)

## پیش‌نیازها

- PHP 8.1 یا جدیدتر
- MySQL 8 یا MariaDB 10.5+
- افزونه‌های PDO، pdo_mysql، fileinfo، DOM، JSON، OpenSSL و mbstring
- Apache با mod_rewrite یا Nginx و SSL فعال

## مرحله ۱: ساخت دیتابیس

در کنترل‌پنل هاست مثل cPanel یا DirectAdmin وارد بخش MySQL Databases شو، یک دیتابیس و کاربر بساز و کاربر را به دیتابیس متصل کن. دسترسی‌های SELECT، INSERT، UPDATE، DELETE، CREATE، ALTER، INDEX و REFERENCES لازم است.

## مرحله ۲: فعال‌کردن نصب از File Manager

1. File Manager هاست را باز کن.
2. وارد پوشه پروژه و سپس پوشه `storage` شو.
3. یک فایل جدید با نام دقیق `install.enabled` بساز.
4. فایل را باز کن و دقیقاً این متن را داخل آن قرار بده:

```text
MILAD-CMS-ALLOW-FIRST-INSTALL
```

5. فایل را ذخیره کن. مسیر آن باید `storage/install.enabled` باشد؛ آن را داخل `public` قرار نده.

این مرحله یک قفل امنیتی است تا بازدیدکننده ناشناس نتواند نصب اولیه و ساخت حساب مدیر را تصاحب کند.

## مرحله ۳: اجرای نصب‌کننده گرافیکی

1. Document Root دامنه را روی پوشه `public` تنظیم کن.
2. به PHP اجازه نوشتن موقت در پوشه‌های `config` و `storage` بده.
3. آدرس `https://دامنه-تو/install` را باز یا تازه‌سازی کن.
4. بعد از سبزشدن بررسی پیش‌نیازها، اطلاعات دیتابیس، عنوان سایت، آدرس دامنه و منطقه زمانی را وارد کن.
5. نام، ایمیل و رمز قوی حساب مالک را تعیین کن.
6. دکمه نصب را بزن. اتصال دیتابیس تست و جدول‌ها ساخته می‌شوند.

## مرحله ۴: ورود به پنل

پس از نصب موفق به `/login` منتقل می‌شوی. پنل مدیریت در `/admin` قرار دارد.

نصب‌کننده فایل `storage/install.enabled` را حذف و قفل `storage/install.lock` را ایجاد می‌کند. فایل قفل را حذف نکن.

## نکات مهم

- ریشه مخزن را به‌عنوان Document Root تنظیم نکن؛ فقط `public` باید عمومی باشد.
- فایل `config/local.php` حاوی اطلاعات اتصال دیتابیس است و باید خصوصی بماند.
- بعد از نصب، دسترسی نوشتن پوشه `config` را در صورت امکان بردار؛ پوشه `storage` برای آپلود و گزارش‌ها همچنان به دسترسی کنترل‌شده نیاز دارد.
- اگر میزبان دیتابیس `localhost` کار نکرد، مقدار صحیح را از شرکت هاستینگ بگیر.
- اگر افزونه‌های PHP یا دسترسی پوشه‌ها مشکل دارند، از پشتیبانی هاست بخواه آن‌ها را فعال کند.

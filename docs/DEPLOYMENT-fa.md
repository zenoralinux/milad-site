# راهنمای نصب و استقرار Milad CMS

## پیش‌نیازها

- PHP 8.1 یا جدیدتر
- MySQL 8 یا MariaDB 10.5+
- افزونه‌های PDO، pdo_mysql، fileinfo، DOM، JSON، OpenSSL و mbstring
- Apache با mod_rewrite یا Nginx
- SSL فعال برای دامنه

## نصب

1. در کنترل‌پنل هاست یک دیتابیس و کاربر اختصاصی بساز و دسترسی‌های SELECT، INSERT، UPDATE، DELETE، CREATE، ALTER، INDEX و REFERENCES را به همان دیتابیس بده.
2. فایل‌های مخزن را آپلود کن.
3. Document Root دامنه را روی پوشه \`public\` تنظیم کن. ریشه مخزن نباید از وب قابل دسترسی باشد.
4. به PHP اجازه نوشتن موقت در پوشه‌های \`config\` و \`storage\` بده.
5. آدرس \`https://دامنه-تو/install\` را باز کن.
6. پیش‌نیازها را بررسی و اطلاعات دیتابیس، عنوان و آدرس سایت، منطقه زمانی و حساب مالک را وارد کن.
7. پس از نصب به \`/login\` منتقل می‌شوی؛ پنل مدیریت در \`/admin\` قرار دارد.

## پس از نصب

- فایل \`config/local.php\` را خصوصی نگه دار و هرگز در مخزن قرار نده.
- فایل \`storage/install.lock\` را حذف نکن.
- HTTPS را اجباری کن.
- از دیتابیس و \`storage/uploads\` نسخه پشتیبان تهیه کن.
- پوشه‌های config و storage را خارج از Document Root نگه دار.

## اجرای محلی

از ریشه پروژه اجرا کن:

\`\`\`bash
php -S 127.0.0.1:8000 -t public public/index.php
\`\`\`

سپس \`http://127.0.0.1:8000/install\` را باز کن. دیتابیس باید از قبل ساخته شده باشد.

Installer دیتابیس را ایجاد نمی‌کند؛ دیتابیس و کاربر را در کنترل‌پنل هاست بساز. اگر اتصال ناموفق بود، میزبان دیتابیس ممکن است \`localhost\` یا آدرس اختصاصی شرکت هاستینگ باشد.

# راهنمای نصب گرافیکی Milad CMS (بدون ترمینال)

## پیش‌نیازها

- PHP 8.1 یا جدیدتر
- MySQL 8 یا MariaDB 10.5+
- افزونه‌های PDO، pdo_mysql، fileinfo، DOM، JSON، OpenSSL و mbstring
- هاست Apache با mod_rewrite و امکان استفاده از فایل‌های .htaccess

## مرحله ۱: ساخت دیتابیس

در کنترل‌پنل هاست مثل cPanel یا DirectAdmin وارد بخش MySQL Databases شو، یک دیتابیس و کاربر بساز و کاربر را به دیتابیس متصل کن. دسترسی‌های SELECT، INSERT، UPDATE، DELETE، CREATE، ALTER، INDEX و REFERENCES لازم است.

## مرحله ۲: آپلود در پوشه site

برای آدرسی مثل https://miladalizadw.ir/site:

1. پوشه‌ای به نام `site` در مسیر اصلی هاست بساز (معمولاً `public_html/site`).
2. محتویات ZIP شاخه CMS را مستقیماً داخل همین پوشه استخراج کن؛ فایل‌های پروژه باید در `public_html/site` باشند و پوشه `public` نیز داخل آن قرار بگیرد.
3. فایل ریشه `.htaccess` پروژه باید فعال باشد. این فایل مسیرهای برنامه را به `public/index.php` هدایت می‌کند و فایل‌های عمومی را از `public/assets` ارائه می‌دهد.
4. پوشه‌های `config` و `storage` باید هنگام نصب برای PHP قابل نوشتن باشند.

نیازی نیست آدرس دامنه را به `public` تغییر بدهی. دسترسی مستقیم به پوشه `public` مسدود می‌شود.

## مرحله ۳: ساخت دیتابیس و فعال‌کردن نصب

1. در File Manager وارد `public_html/site/storage` شو.
2. یک فایل با نام دقیق `install.enabled` بساز.
3. دقیقاً این متن را داخل آن قرار بده و ذخیره کن:

```text
MILAD-CMS-ALLOW-FIRST-INSTALL
```

این مرحله قفل امنیتی نصب اولیه است تا بازدیدکننده ناشناس نتواند حساب مالک سایت را تصاحب کند.

## مرحله ۴: اجرای نصب‌کننده

1. آدرس `https://miladalizadw.ir/site/install` را باز کن.
2. پیش‌نیازهای سرور را بررسی کن؛ بعد از ساخت فایل فعال‌سازی صفحه را تازه‌سازی کن.
3. اطلاعات دیتابیس، عنوان سایت و منطقه زمانی را وارد کن.
4. آدرس سایت را دقیقاً `https://miladalizadw.ir/site` قرار بده.
5. نام، ایمیل و رمز قوی حساب مالک را وارد کن و نصب را انجام بده.

نصب‌کننده جدول‌ها و حساب مالک را می‌سازد، تنظیمات را در `config/local.php` ذخیره می‌کند، فایل فعال‌سازی را حذف و نصب را قفل می‌کند.

## مرحله ۵: ورود

- صفحه ورود: `https://miladalizadw.ir/site/login`
- پنل مدیریت: `https://miladalizadw.ir/site/admin`

## اگر به‌جای نصب 404 می‌بینی

- مطمئن شو آخرین ZIP شاخه `feat/milad-cms-foundation-20261114` را استخراج کرده‌ای؛ `main` هنوز حاوی این CMS نیست.
- در هاست Apache، `mod_rewrite` باید فعال باشد و `.htaccess` نباید توسط تنظیمات هاست غیرفعال شده باشد.
- محتوای ZIP را داخل خود پوشه `site` استخراج کن، نه داخل یک پوشه تو در تو مثل `site/milad-site-...`.
- وجود این فایل را بررسی کن: `site/public/index.php`.
- اگر کنترل‌پنل امکان تعیین Document Root مستقل برای زیرپوشه را می‌دهد، روش جایگزین این است که Document Root را مستقیماً روی `site/public` بگذاری؛ در آن حالت آدرس نصب به شکل `https://دامنه/install` خواهد بود، نه `/site/install`.

## نکات امنیتی

- ریشه پروژه را بدون `.htaccess` عمومی نکن.
- `config/local.php` حاوی اطلاعات دیتابیس است و نباید از وب قابل دریافت باشد.
- پس از نصب، دسترسی نوشتن پوشه `config` را در صورت امکان بردار؛ پوشه `storage` برای آپلودها به دسترسی کنترل‌شده نیاز دارد.
- از HTTPS، کاربر دیتابیس اختصاصی و رمزهای قوی استفاده کن.
